# Network Dataset Information

**Dataset:** UNSW-NB15 Dataset

**Source:** [UNSW Canberra Cyber – Official Dataset](https://research.unsw.edu.au/projects/unsw-nb15-dataset)

This dataset contains normal network traffic and different types of network attacks. It is used to train and evaluate our Random Forest-based network threat detection model.

**Dataset Files:**
- `UNSW_NB15_training-set.csv`
- `UNSW_NB15_testing-set.csv`

**Labels:**
- 0 – Normal
- 1 – Attack

**Purpose:** To identify malicious network activity and distinguish it from normal network traffic.

The dataset is downloaded separately due to its file size. Place both CSV files in the `Network_Detection` directory before running the training script.

**Source:** Australian Centre for Cyber Security (ACCS).
